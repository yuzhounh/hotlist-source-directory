# 热榜来源目录

[![License: CC BY 4.0 + MIT](https://img.shields.io/badge/License-CC%20BY%204.0%20%2B%20MIT-f59e0b.svg)](LICENSE)

一个可搜索、可分页浏览的中文热榜来源目录，收录多个热榜聚合网站及 TopHub 分类来源。

## 在线访问

[打开在线目录](https://yuzhounh.github.io/hotlist-source-directory/)

## 亮点特性 (Features)

- 浏览 6 个热榜聚合网站的来源卡片
- 按 TopHub 分类查看来源
- 支持关键词搜索和分页
- 支持浅色、深色主题

## 本地使用 (Quick Start)

```bash
git clone https://github.com/yuzhounh/hotlist-source-directory.git
cd hotlist-source-directory
```

本项目为纯静态单页，无需安装依赖或构建，直接打开 `index.html` 即可使用。
